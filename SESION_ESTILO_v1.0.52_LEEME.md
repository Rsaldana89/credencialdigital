# v1.0.52 - Estilo de sesión

Esta versión únicamente ajusta la presentación del encabezado administrativo.

## Cambios

- Nombre de usuario y rol en un bloque compacto integrado al encabezado.
- Indicador dorado para identificar visualmente la sesión activa.
- Botón **Cerrar sesión** con el mismo lenguaje visual corporativo del sitio.
- Mejor distribución en escritorio y celular.
- Cache busting del CSS global con `styles.css?v=1.0.52`.

## Importante

No hay cambios de base de datos, autenticación, contraseñas, permisos, eventos, credenciales o QR.
